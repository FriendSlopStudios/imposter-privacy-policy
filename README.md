# Legal-site publishing checklist

These HTML files are release drafts, not a substitute for legal advice.

Before entering the URLs in Play Console:

1. Obtain counsel and native-language review.
2. Publish this directory at a permanent public HTTPS domain controlled by the publisher.
3. Confirm both `/index.html` and `/terms.html` return HTTP 200 without login, redirects to downloads, or a PDF viewer.
4. Replace every policy/listing URL in Play Console with that permanent domain.
5. Reconcile the final text with the Data Safety, Ads, Target Audience, and content-rating answers after SDK inspection.
